# Commerce 정보 센터 정보

Commerce 정보 센터는 Adobe Commerce 설명서 생태계의 제품 간 진입점입니다. 여러 문서 사이트를 검색하지 않고도 Adobe Commerce, [!DNL Adobe Commerce Optimizer], [!DNL Adobe Commerce as a Cloud Service] 및 관련 Commerce 서비스에서 올바른 제품, 구현 지침 및 아키텍처 권장 사항을 찾을 수 있습니다.

각 제품에 대한 권위있고 심층적인 설명서는 자체 안내서에서 계속 제공됩니다. 정보 센터는 한 곳에서 시작하여 올바른 대상에 더 빨리 도달할 수 있도록 해당 콘텐츠를 선별하고 연결합니다.

## 시작

| 섹션 | 사용 대상 |
| ------- | --------- |
| [역할별 시작](get-started/get-started-by-role.md) | 비즈니스 실무자, 머천다이저, 관리자, 개발자, 솔루션 설계자 또는 파트너 등의 역할을 기반으로 출발점을 찾습니다. |
| [플랫폼 및 서비스](portfolio/platform-and-services.md) | Adobe Commerce 제품 포트폴리오를 이해하고 요구 사항에 맞는 제품 및 서비스를 식별합니다. |
| [Commerce 옵션 선택](portfolio/choose-commerce-option.md) | 배포 환경 설정, 운영 요구 사항 및 원하는 인프라 관리 수준에 따라 적합한 Commerce 오퍼링을 선택하는 방법에 대한 지침을 확인하십시오. |
| [상점](storefronts/overview.md) | Adobe Commerce 내에서 사용할 수 있는 다양한 상점 옵션에 대해 알아봅니다. |
| [Commerce용 AEM Assets 통합](aem-assets/aem-assets-integration.md) | 모든 Commerce 또는 Optimizer 아키텍처에 중앙 집중식 디지털 에셋 관리를 추가합니다. |
| [API](apis/commerce-apis.md) | Commerce Foundation, Storefront Services 및 Commerce Optimizer에서 사용되는 API 제품군을 살펴보십시오. |
| [구현 가이드](implementation-guides/overview.md) | 상점 구축 또는 Commerce 서비스 연결과 같은 일반적인 구현 여정에 대한 제품 간 지침을 따르십시오. |
| [아키텍처 옵션](architecture-options/overview.md) | 지원되는 Commerce 아키텍처를 비교하고 여러 Commerce 제품에 걸친 참조 패턴을 검토하십시오. |
| [인사이트 및 지침](guidance-and-insights/overview.md) | 백서, 보안 권장 사항 및 모범 사례를 포함한 전략적 지침을 확인할 수 있습니다. |
| [마이그레이션 및 채택](migration-adoption/overview.md) | 아키텍처 간 이동 또는 Adobe Commerce Optimizer의 단계적 채택을 계획합니다. |

>[!NOTE]
>
>Commerce 정보 센터는 제품 설명서를 대체하지 않습니다. 단계별 구성 및 참조 자료는 각 섹션의 링크를 따라 신뢰할 수 있는 제품 안내서를 참조하십시오.
